# User Offboarding Checklist

Use this for every leaver. Complete the steps in order, and record the date and your initials against each one.

## Before the leaving date
- [ ] Confirm the leaving date and the line manager's instructions
- [ ] Confirm who inherits the user's files, mailbox and shared resources
- [ ] Check for any open requests or assets assigned to the user

## On the leaving date
- [ ] Disable the user account (do not delete it yet)
- [ ] Reset the password and revoke active sessions and tokens
- [ ] Remove MFA registrations and trusted devices
- [ ] Remove from distribution lists, security groups and shared mailboxes
- [ ] Set an out-of-office or forward the mailbox, as the manager requests
- [ ] Revoke VPN, remote access and third-party application access

## Licences and data
- [ ] Back up or transfer mailbox and file storage to the nominated owner
- [ ] Reassign or reclaim software licences
- [ ] Remove the user from shared drives and collaboration tools

## Equipment
- [ ] Collect laptop, phone, security badge and accessories
- [ ] Update the asset register
- [ ] Wipe and reimage returned devices before reissuing

## After the leaving date
- [ ] Delete the account after the agreed retention period
- [ ] Close the offboarding request and note any exceptions

## Notes
- Disable first and delete later, in case data or access is needed again.
- Always confirm the request comes from HR or the line manager.
