# Printer Troubleshooting Guide

## Symptoms
- Print jobs stuck in the queue or not printing
- Printer shows as offline or unavailable
- Garbled, blank or poor-quality prints
- Paper jams or error lights on the device

## First checks
1. Check the printer is powered on, has paper and toner, and shows no error on its display.
2. Check it is connected to the network (cable or Wi-Fi) and can print a test page from its own menu.
3. Check whether other users can print to the same printer.
4. Confirm the user selected the correct printer.

## Fixes, in order
1. Cancel the stuck jobs and resend one test document.
2. Restart the printer, wait a minute, then try again.
3. Windows: restart the Print Spooler service (services.msc > Print Spooler > Restart).
4. Mac: System Settings > Printers & Scanners, remove the printer and add it again.
5. Reinstall or update the printer driver.
6. Re-add the printer using its IP address instead of its name.

## Escalate if
- No users can print to the device (likely a hardware or network fault).
- The printer shows a hardware error, such as a fuser or drum fault.
- The printer is unreachable on the network from any device.
- Supplies or maintenance are needed that you cannot order or perform.

## Information to collect
Printer name and location, device model, user's OS and driver version, exact error message, whether other users are affected, time the problem started.
